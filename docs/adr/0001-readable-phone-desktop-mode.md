# 手机电脑模式优先保持可读布局

产品要求手机即使请求电脑模式，也保持正常字号和可操作的布局。浏览器可能提供约 980px 的布局视口，因此在窄触控屏的布局视口明显大于屏幕宽度时，由 `SiteViewport` 补偿应用内容的缩小比例；补偿限于应用外壳，不缩放 `html` / `body`，不修改 viewport 标签或用户双指缩放。

显示宽度结合屏幕宽度和 `visualViewport.width * scale` 判断；后者在双指缩放时保持稳定，也能补充电脑模式伪装的屏幕宽度。超过 10% 的差异才进行补偿，避免滚动条和像素舍入被误识别为电脑模式。

组件统一使用 `site-sm` / `site-md` / `site-lg` 容器查询，按外壳的实际可用宽度排版。通用 Tailwind 断点保留原语义。视口高度也在外壳内换算，避免缩放后的外框被再次拉长。正常手机、平板和电脑默认倍率为 1。

这是站点明确选择的展示策略，会覆盖手机浏览器电脑模式的桌面布局请求。自动识别依赖浏览器提供有效的屏幕尺寸、触控信息及 CSS zoom 支持；全部伪装为桌面设备的浏览器无法可靠识别，需要上线后进行 X 内置浏览器实机验证。保留手机两种模式、旋转、切换模式、页面导航、双指缩放及普通桌面的浏览器回归检查。
